01 Bentuk Umum & Konsep Dasar Akar Persamaan Kuadrat

Persamaan Kuadrat adalah persamaan polinomial berderajat dua dengan bentuk umum:

ax2 + bx + c = 0  (a ≠ 0; a, b, c ∈ ℝ)

Akar-Akar (x1 dan x2) adalah nilai peubah x yang memenuhi persamaan (titik potong grafik fungsi kuadrat pada sumbu-X).

Jika akar-akar x1 dan x2 diketahui, persamaan kuadrat dapat disusun dengan Metode Perkalian Faktor:

(x − x1)(x − x2) = 0  ⇒  x2 − (x1 + x2)x + (x1 · x2) = 0

Contoh: Akar x1 = 2 dan x2 = 3 ⇒ (x − 2)(x − 3) = 0 ⇒ x2 − 5x + 6 = 0.

02 Menyusun Persamaan Kuadrat dengan Rumus Vieta (Jumlah & Hasil Kali)

Berdasarkan Teorema Vieta, jumlah dan hasil kali akar-akar persamaan kuadrat ax2 + bx + c = 0 berkaitan langsung dengan koefisiennya:

Jumlah Akar (S)
x1 + x2 = −b/a
Hasil Kali Akar (P)
x1 · x2 = c/a

Dengan mensubstitusi nilai jumlah dan hasil kali ke dalam formula baku:

x2 − (x1 + x2)x + (x1 · x2) = 0

Contoh: Jika x1 + x2 = 7 dan x1 · x2 = 10 ⇒ Persamaan kuadratnya langsung: x2 − 7x + 10 = 0.

Kuis: Jika jumlah akar x1 + x2 = −4 dan hasil kali akar x1 · x2 = −5, persamaannya adalah...

03 Menyusun Persamaan Kuadrat Baru yang Berkaitan

Untuk menyusun persamaan kuadrat baru yang akar-akarnya (α dan β) berhubungan dengan akar persamaan lama (x1, x2):

1. Persamaan Lama: Hitung nilai (x1 + x2) dan (x1 · x2).
2. Akar Baru: Hitung (α + β) dan (α · β) menggunakan relasi yang diberikan.
3. Formula: x2 − (α + β)x + (α · β) = 0

Karakteristik Relasi Akar Baru:

  • Akar Berlawanan (−x1, −x2): Jumlah = −(x1 + x2), Kali = x1x2
  • Akar Berkebalikan (1/x1, 1/x2): Jumlah = (x1+x2)/(x1x2), Kali = 1/(x1x2)
  • Akar n kali (n·x1, n·x2): Jumlah = n(x1+x2), Kali = n2(x1x2)

Glosarium Istilah Kunci
Persamaan Kuadrat
Persamaan polinomial satu variabel berpangkat tertinggi dua dengan bentuk umum ax² + bx + c = 0, di mana a, b, c ∈ ℝ dan koefisien a ≠ 0.
Akar Persamaan Kuadrat
Nilai penyelesaian variabel x (biasanya ditulis x₁ dan x₂) yang membuat persamaan bernilai benar. Secara geometri, akar adalah titik potong kurva dengan sumbu-X (y = 0).
Koefisien (a dan b)
Faktor pengali konstanta di depan variabel. Koefisien a menentukan kelengkungan dan arah keterbukaan kurva, sedangkan b mempengaruhi posisi sumbu simetri parabola.
Konstanta (c)
Suku bilangan tetap pada persamaan kuadrat yang tidak mengikat variabel x. Nilai c secara visual menunjukkan titik potong kurva parabola dengan sumbu-Y di koordinat (0, c).
Jumlah Akar (x₁ + x₂)
Hasil penjumlahan kedua akar yang dirumuskan melalui Teorema Vieta: x₁ + x₂ = -b/a. Nilai ini berperan langsung membentuk koefisien suku tengah pada formula x² - (x₁ + x₂)x + (x₁ · x₂) = 0.
Hasil Kali Akar (x₁ · x₂)
Hasil perkalian antara kedua akar yang dirumuskan melalui Teorema Vieta: x₁ · x₂ = c/a. Nilai ini menjadi konstanta ujung persamaan kuadrat baru yang disusun.
Diskriminan (D)
Nilai pembeda karakteristik akar yang dirumuskan D = b² - 4ac. Jika D > 0 memiliki dua akar real berbeda, D = 0 memiliki dua akar kembar, dan D < 0 tidak memiliki akar real.
Kurva Parabola
Bentuk visual kurva mulus simetris dari grafik fungsi kuadrat. Parabola terbuka ke atas jika nilai a > 0 (titik puncak minimum) dan terbuka ke bawah jika nilai a < 0 (titik puncak maksimum).
Bentuk Perkalian Faktor
Metode menyusun persamaan kuadrat dengan mengalikan faktor linear akar-akarnya, yaitu a(x - x₁)(x - x₂) = 0. Melalui ekspansi aljabar bentuk ini, ditemukan identitas formula jumlah dan hasil kali akar.
Akar Berlawanan & Berkebalikan
Kondisi istimewa relasi akar: (1) Akar Berlawanan (x₁ = -x₂ ⇒ b = 0, kurva simetris di sumbu-Y), serta (2) Akar Berkebalikan (x₁ = 1/x₂ ⇒ c = a, hasil kali akarnya selalu sama dengan 1).
